# Capturas del relevamiento

Las capturas **no se editan ni se reemplazan por reconstrucciones**: el PDF las incrusta tal cual.
Dejá cada archivo en esta carpeta con el nombre exacto de la tabla y regenerá el documento:

```bash
python3 docs/pdf/build.py
```

Las que falten se muestran como espacio reservado con el nombre esperado, así el PDF siempre se
puede generar aunque el set esté incompleto.
